# Video Analysis Index

Scaffold only. On first run this is copied to `..\video-research\INDEX.md`, outside the repo.
The live index is never committed — this template is what a fresh clone starts from.

One row per analyzed video. Append after every run — never rewrite existing rows.

**Multiplier is views ÷ subscribers.** It is the reason this index exists: it separates videos that
outperformed their channel from videos that merely have a big channel behind them. Sort your
attention by multiplier, not by view count.
